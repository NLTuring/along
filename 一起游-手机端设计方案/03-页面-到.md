# 03 页面设计 · 到（Landing）

> 每页按"目的 / 布局 / 玻璃用法 / 交互 / 状态"写。文案 key、数据接口、埋点、验收沿用策划书对应小节，这里不重复，只写手机端的呈现。

## 1. 首次打开

**目的**：三秒内让人明白这是什么，并且不打断地进入到达表单。

现有欢迎页是一个三条说明的弹层（`welcome()`）。改为一个动作：

```
┌────────────────────────┐
│                        │
│   ╭──────────────╮     │
│   │              │     │  ← 舷窗形，里面是上海此刻天色下的
│   │   （照片）    │     │    城市照片，窗上盖着遮光板
│   │ ▒▒▒▒▒▒▒▒▒▒▒▒ │     │
│   │ ▒▒ 遮光板 ▒▒▒ │     │
│   ╰──────▂▂──────╯     │  ← 遮光板下沿有一个小拉手
│                        │
│  Land in China.        │  ← hero.title，衬线体 36
│  Leave with a friend   │
│  and a film.           │
│                        │
│  Pull the shade up     │  ← 13px 提示，2 秒后淡入
└────────────────────────┘
```

- 用户向上拉遮光板，窗后的城市露出来，同时到达表单从下方升起。
- 不想拉的人：点任意位置，或等 4 秒，遮光板自己升起。读屏用户直接看到表单。
- 只在第一次打开出现。权限（相机、定位）不在这里要，等到真正用到时再问。

**埋点**：`landing_view`。

## 2. Trip 阶段 A · 到达表单（策划书 §6.1 + §6.2）

**目的**：用最少输入生成计划。策划书的落地页表单和建计划页在手机端合并为一个连续页面，分两步。

### 第一步：什么时候到

```
┌────────────────────────┐
│ ░░░░ 天空区 ░░░░░  EN  │  ← 上海此刻的天色
│  ╭────────────╮        │
│  │  舷窗照片   │        │  ← 高度随滚动缩小
│  ╰────────────╯        │
│                        │
│ Three days, planned    │  ← plan.new.title
│ around you.            │
│                        │
│ ┌────────────────────┐ │
│ │ When do you land   │ │  ← 纸面卡片，不是玻璃
│ │ [Fri 13 Nov] [18:00]│ │
│ │                    │ │
│ │ Where              │ │
│ │ (Shanghai)(Nanjing)│ │
│ │                    │ │
│ │ How long           │ │
│ │ [ 3 ][ 5 ][ 7 ] days│ │
│ └────────────────────┘ │
│                        │
│ ┌────────────────────┐ │
│ │   Build my 3 days  │ │  ← 墨色主按钮，文字随天数变
│ └────────────────────┘ │
│  Join the waitlist     │  ← 文字链接
└────────────────────────┘
```

- **日期选择是招牌交互"登机牌"**：点日期，从底部升起一张登机牌样式的厚玻璃卡。左右滑动换日期，上下滚动换时间，右侧"撕票线"是确认区，向右一划确认。也可以点卡上的 Done。
- **选了到达时间，天空区立刻变成那个时刻的天色**。选 18:00 就是傍晚的暖色，选 23:00 就是夜色。用户直观看到"我落地时天是这样的"。

### 第二步：喜欢什么（点主按钮后在同页展开，不跳页）

- 兴趣多选：Food / Photography / History / No crowds / Family / Accessible。做成**窗玻璃贴片**：未选是清玻璃描边，选中后变成实色纸片并微微倾斜 1 到 2 度，像贴在窗上的便签。
- 节奏：Slow / Balanced / Packed，三段滑杆。拖动时旁边的小时间轴示意图跟着变疏变密。
- 预算（可选）：收起状态，点开才显示。
- 主按钮文字变为 Build my plan。

### 生成中

- 舷窗放大到占满上半屏，窗外是云层缓慢后移（天色与到达时间一致）。
- 窗下方依次出现进度文案（策划书："Checking opening hours…"），每条完成后前面出现一个小勾。
- 12 秒后显示 `plan.new.slow` 和 "See a sample plan" 按钮（策划书的模板入口）。
- 成功：云层散开，窗外露出第一站的照片，舷窗展开成计划详情页的头图。
- 失败：表单输入原样保留，显示错误码、重试和模板入口。

**埋点**：`plan_cta_click` `plan_started` `plan_generated` `plan_failed` `waitlist_submit`。

## 3. Trip 阶段 B · 计划详情（策划书 §6.3）

**目的**：让人相信这三天走得通。

```
┌────────────────────────┐
│ ░ 天空区（当天预报）░ ✉ │
│ Your 3 days            │  ← plan.title
│ Shanghai – Nanjing     │
│ 13 Nov – 15 Nov        │
│ ( 18° rain after 16:00 )│  ← 薄玻璃胶囊，点开看天气
│                        │
│ [Day 1] [Day 2] [Day 3] │  ← 天切换，吸顶后变中档玻璃
│                        │
│ 09:30 ● Yu Garden & …  │
│       │ 豫园·老城厢     │  ← 中文小字
│       │ Go before 10.  │
│       │ 90 min  ¥40    │
│       ┊ walk 12 min    │  ← 两站之间的交通，虚线
│ 12:00 ● …              │
│                        │
│ ┌─ If it rains ──────┐ │  ← accent-soft 底
│ │ Swap the riverside…│ │
│ └────────────────────┘ │
│ On the ground, no hotel│
│                  ¥657  │
│ ┌────────────────────┐ │
│ │ Find a local friend│ │
│ └────────────────────┘ │
│  Save   Share   Map    │
└────────────────────────┘
```

**设计细节**

- **站点照片是小窗**：时间轴上每一站右侧有一个 56×56 的圆角小窗，里面是地点照片。向下滚动时，照片在窗内有轻微的反向位移（视差），像隔着窗看过去。
- **当前选中的站点**用印泥红圆点；其余是墨色空心圆。
- **天切换**：左右滑动整个时间轴也能切天。切天时天空区的颜色换成那一天的预报。
- **某一天还在生成**：那一天的时间轴盖着长虹玻璃，上面一行字 "Day 2 is still being planned"。生成完，玻璃向右滑开。
- **改一天**：每天标题右侧一个 Regenerate 按钮。免费次数用完后，按钮上盖一小块长虹玻璃和一把锁，点了弹出通行证说明。
- **营业时间冲突**：站点下方一行 `--danger` 色的提示，带图标。
- **雨天备选卡**：当天预报有雨时，这张卡自动移到时间轴最上方。
- 费用显示人民币为主、美元约值在旁（策划书 §5.1 格式）。

**行前倒计时**：标题下方一行 "You land in 2 days 4 hours"。落地前 24 小时内，这一行变成一张纸面卡片，列出三件落地要办的事（支付、网络、交通），每件可以勾掉。

**埋点**：`plan_view` `plan_day_switch` `plan_regenerate` `plan_cta_friend`。

## 4. 地点详情（策划书 §6.4）

**呈现**：从被点的那个小窗"长"出来的弹层。小窗放大成弹层顶部的大图，其余内容从下方跟上。不跳页。

```
┌────────────────────────┐
│ （地点大图，可左右滑）  │
│                        │
├────────────────────────┤  ← 厚玻璃弹层，可上拉到全高
│ Yu Garden & the old town│
│ 豫园·老城厢      [复制] │  ← 中文名可一键复制/放大给司机看
│ History   4.6          │
│                        │
│ 90 min   ¥40     08:45–16:45 │
│                        │
│ Go before 10. The back │
│ lanes behind the garden│
│ are quieter…           │
│                        │
│ （小地图，点击进全屏地图）│
│                        │
│ [Add to day ▾] [Directions] [Save] │
└────────────────────────┘
```

- **"给司机看"**：点中文名，屏幕变成白底黑字的超大中文地名（占满屏）。这是入境游客最实际的需求之一。再点一下恢复。
- Add to day：点开选第几天，加入后时间轴即时更新（策划书验收项）。
- Directions：打开外部导航（现有 `Android.openExternal`）。
- 无图用纸色占位加地点类别图标；无坐标显示"Location to be confirmed"。

**埋点**：`poi_open` `poi_add` `poi_directions`。

## 5. 地图

**布局**：复用现有结构——原生百度地图铺在下面，网页的玻璃抽屉盖在上面（`drawers.js`，三档高度）。

- 顶部：返回钮 + 天切换（玻璃胶囊）。
- 底部抽屉三档：
  - 低：只露出下一站的名称和步行时间。
  - 中：当天全部站点的横向卡片，左右滑动，地图跟着移到对应站点。
  - 高：完整时间轴。
- 地图上的站点标记是带序号的小圆章，当前站是印泥红。
- 抽屉的玻璃做法见《01-视觉系统》§2.4：新系统由原生层模糊，旧系统用不透明度更高的兜底样式。

**英文地图的问题**：百度地图底图是中文。v1 在标记和抽屉里显示英文名，底图保持中文；策划书技术规格里网页端用 Mapbox，手机端是否更换地图 SDK 登记在《08-改造落地》§7 待决策。
