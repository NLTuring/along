# 05 页面设计 · 带走（Studio）

> 文案 key、接口、埋点、验收沿用策划书对应小节。数量、时长、价格来自策划书 §6.10–6.14 与 §7。

---

## 1. 取景键弹层

轻点底部中间的取景键，升起一块厚玻璃弹层，四个选项，每个一行，左侧图标，右侧一句说明：

| 选项 | 说明 | 去向 |
|---|---|---|
| Take a photo | 存进你的相册 | 原生相机 |
| Make a film | 3 到 12 张照片变成一条竖屏短片 | `studio` |
| Make a souvenir | 一张照片变成冰箱贴或钥匙扣 | `craft/:craftId` |
| Post a story | 发到社区 | 发布弹层 |

首页下拉开相机的手势保留（现有 `#camera-pull`）。改为"拉下遮光板"的样子：下拉时一块玻璃板从顶部跟着手指下来，板上是一个镜头图标；拉过阈值松手进入相机。

## 2. 选片（策划书 §6.10）

**目的**：把相册变成成片。

```
┌────────────────────────┐
│ ←  Six photos. One film.│  ← studio.title
│ Pick the moments. We   │
│ handle the edit, the   │
│ captions and the sound.│
│                        │
│ ┌───┬───┬───┐          │
│ │ 1 │   │ 2 │          │  ← 相册网格，选中的显示序号
│ ├───┼───┼───┤          │
│ │   │ 3 │   │          │
│ ├───┼───┼───┤          │
│ │ + │   │   │          │  ← 第一格是上传
│ └───┴───┴───┘          │
├────────────────────────┤
│ ▭ ▭ ▭ ▫ ▫ ▫            │  ← "胶片条"，中档玻璃，固定在底部
│ Style (China Travel)(Street Food)(Slow Walk)
│ Length [15s][30s][60s] │
│ [ Make my film ]       │
└────────────────────────┘
```

**设计细节**

- **招牌交互"胶片条"**：点一张照片，它飞进底部的胶片条里，按点选顺序排列。选择顺序就是镜头顺序（策划书验收）。在胶片条里长按拖动可以调顺序，向上甩可以移除。
- 胶片条上方显示计数 "4 of 12"。不足 3 张时主按钮禁用，文字 "Pick at least 3"。
- **风格**三选一（枚举 `CHINA_TRAVEL` `STREET_FOOD` `SLOW_WALK`）。选中时，胶片条里第一张照片上出现该风格的字幕样例，让人预知效果。
- 时长三选一：15 / 30 / 60 秒。
- 无照片：空状态一句话 + "Take a photo" + "Upload"。
- 重复点击主按钮不重复创建（幂等键）。

**埋点**：`studio_open` `studio_select` `film_create`。

## 3. 成片预览（策划书 §6.11）

**目的**：30 秒内看到成品并愿意发出去。无底部导航。这一页是全 App 唯一的深色页面，因为它是放映厅。

```
┌────────────────────────┐
│ ←                      │  ← 深色背景（照片模糊放大后压暗）
│   ╭──────────────╮     │
│   │ InsTrip      │     │  ← 9:16 取景框，圆角 26
│   │              │     │
│   │   （成片）    │     │
│   │              │     │
│   │ First bowl of│     │  ← 字幕，在安全区内
│   │ noodles, ¥18.│     │
│   │ ▬▬▬▭▭▭▭▭▭▭▭  │     │  ← 分段进度条，一段一个镜头
│   ╰──────────────╯     │
│                        │
│ [ Share ]              │  ← 白色实底主按钮（深色页反色）
│ [ Save ]  [ Edit captions ]│
│ English captions, original music, no watermark │
└────────────────────────┘
```

**渲染中（招牌交互"显影"）**

- 取景框里先是一块长虹玻璃，后面隐约是用户选的照片在缓慢轮换。
- 随着渲染进度推进，长虹玻璃的棱纹从左到右逐条变清，像照片在显影。
- 进度文案在框下方轮换（策划书："Cutting your film…"）。
- 完成的一刻，最后一条棱纹消失，影片自动开始播放。
- 超过 3 分钟：提示可以离开，完成后邮件通知（策划书）。
- 失败：显示重试；重试两次仍失败，提示 "Try 3 different photos"（策划书流程 D）。

**播放**

- 点左半边回上一镜，点右半边到下一镜，长按暂停。和主流短视频应用的手势一致，不需要学习。
- 分段进度条每段对应一个镜头。
- Edit captions：点字幕直接在画面上改字，每行最多 32 个字符、最多两行（策划书 §7.6），超出时计数变红。
- Save：调用原生 `Android.downloadVideo` 存到相册，完成后提示 "Saved to your photos"。

**埋点**：`film_render_started` `film_render_succeeded` `film_save` `film_share`。

## 4. 分享（策划书 §6.12）

**呈现**：厚玻璃弹层，盖在成片预览上。

```
┌────────────────────────┐
│ ┌──────┐               │
│ │ 封面 │ Three days in  │  ← 分享卡：一张拍立得
│ │      │ Shanghai       │
│ │      │ 30 s    ▣ QR   │
│ └──────┘               │
│                        │
│ Caption                │
│ ┌────────────────────┐ │
│ │ 72 hours in China: │ │  ← 可编辑
│ │ noodles at noon…   │ │
│ └────────────────────┘ │
│                 142/220│
│ #ChinaTravel #InsTrip  │  ← 固定话题，不可删
│                        │
│ [ Open TikTok ]        │
│ [Copy caption] [Save film]│
│ TikTok does not open on│
│ mainland China networks.│
└────────────────────────┘
```

**设计细节**

- **分享卡是一张拍立得**，沿用现有数字藏品的拍立得样式。**可以翻面**（现有"翻面写字"交互）：正面是封面和标题，背面是用户手写的一句话和二维码。导出的分享图是正面。
- 文案上限 220 字符，右下角实时计数（策划书验收）。
- **Open TikTok**：尝试唤起 App。唤起失败时，弹层内就地换成三步说明：1 影片已存到相册 2 文案已复制 3 打开 TikTok 手动发布（策划书的降级要求）。
- 二维码指向 `/trip/[id]`（策划书验收）。
- 系统分享面板作为第二入口（现有 `Android.shareFile`）。

**埋点**：`share_open` `share_click` `caption_copy`。

## 5. 文创（策划书 §6.13）

**目的**：一张照片变成能带走的纪念品。

**布局**：上半屏是展示台，下半屏是分步操作，一步一屏，底部一行步骤点。

```
┌────────────────────────┐
│ ←  Make a souvenir     │
│                        │
│      ╭──────────╮      │
│      │  3D 预览  │      │  ← 展示台：可用手指转动
│      │ （冰箱贴） │      │    下方一圈柔和的地面投影
│      ╰──────────╯      │
│                        │
├────────────────────────┤  ← 中档玻璃操作区
│ Pick a shape           │
│ ( 拱形 )( 椭圆 )( 花边 )( 圆角方 )│
│                        │
│ ● ● ○ ○ ○              │  ← 步骤点
│ [ Next ]               │
└────────────────────────┘
```

**五步**

1. **选照片**：从相册选一张。
2. **选产品**：Magnet $29 / Keychain $24。两个产品并排，各有一张实物图。
3. **选形状**：拱形 / 椭圆 / 花边 / 圆角方形。点形状时，展示台上的照片立刻被裁成那个形状。
4. **生成**：先出设计图，再出 3D。等待时展示台上盖长虹玻璃并显影，与成片的等待方式一致。
5. **带走**：
   - "Download digital version"（免费，PNG，立即可得）。
   - "Order the real one"：收货信息表单 → 确认地址 → 支付。写明 7 到 10 个工作日、运费 $6、定制品不退货但质量问题重做（策划书 §7.6）。

**设计细节**

- **招牌交互"手机当展台"**：3D 预览除了手指拖动，还会随手机倾斜轻微转动，高光跟着移动，像手里真拿着一件东西。可在设置里关闭；系统开启"减少动态效果"时自动关闭。
- 3D 加载失败或设备不支持时，降级为正面、侧面、背面三张静态图（策划书）。
- 下单后页面显示订单号和一条进度线：Ordered → Produced → Shipped，发货后显示运单号（策划书验收）。

**埋点**：`craft_start` `craft_design_done` `craft_model_done` `craft_order` `craft_download`。

## 6. 社区（策划书 §6.14）· Stories 页签

**目的**：社会证明，给新用户看"别人的三天是什么样"。

- 顶部两个页签：Stories / Guides。
- 双列瀑布流，卡片是纸面：图、标题、作者、城市。**图片上不盖玻璃**，只有左下角一个薄玻璃城市标签。
- 点卡片：图片放大成详情页头图（共享元素转场），正文在下。
- 点赞：双击图片或点心形图标。心形用 `--accent`，这是强调色少数被允许的用法之一。
- 发布：从取景键弹层的 "Post a story" 进入。文字加图片。
- **审核中的帖子**：只有作者自己能看到，卡片上盖一块长虹玻璃，标注 "In review"（策划书：发布后状态 PENDING 仅自己可见）。
- 举报：卡片更多菜单里。
- 未登录可看不可发（策划书验收）；点发布时升起登录弹层。

**埋点**：`community_view` `post_open` `post_like` `post_publish` `post_report`。
