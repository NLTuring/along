# 06 页面设计 · 系统页

> 规则数值（验证码时效、锁定次数、删除期限、通行证价格）全部来自策划书 §6.15–6.20 与 §7.1。

---

## 1. 登录（策划书 §6.16）

**呈现**：厚玻璃全高弹层，盖在当前页面上。登录完弹层收起，原页面和已做的选择都还在。

```
┌────────────────────────┐
│ ×                      │
│                        │
│ Sign in with your email│  ← 衬线体 26
│ No password. We send   │
│ you a 6-digit code.    │
│                        │
│ Email                  │
│ ┌────────────────────┐ │
│ │ you@mail.com       │ │
│ └────────────────────┘ │
│ ☐ I agree to the Terms │
│   and Privacy Policy   │
│                        │
│ [ Send code ]          │
└────────────────────────┘
        ↓ 发送后同一弹层内切换
┌────────────────────────┐
│ ←                      │
│ Enter the code         │
│ Sent to you@mail.com   │
│                        │
│  ┌─┐┌─┐┌─┐ ┌─┐┌─┐┌─┐   │  ← 六个格子，每格是一小块玻璃窗
│  │4││1││7│ │ ││ ││ │   │
│  └─┘└─┘└─┘ └─┘└─┘└─┘   │
│                        │
│ Code expires in 09:42  │
│ Send again in 0:38     │
└────────────────────────┘
```

**设计细节**

- **六格验证码是六扇小窗**：空格是清玻璃；输入后变成纸色实底，数字用衬线体。六格填满自动提交，不需要再点按钮。
- 支持从短信或邮件通知栏自动填充、支持粘贴整串数字。
- 验证码 10 分钟有效，格子下方显示倒计时。
- 输错：六格左右轻晃一次，下方红字 "That code is not right. 4 tries left."
- 输错 5 次：格子变磨砂并禁用，显示 "Too many tries. Try again in 15 minutes."
- 同一邮箱一小时内发送超过 5 次：显示 "You have asked for too many codes. Try again later."
- 首次登录须勾选同意条款（策划书 §6.19）；条款链接在弹层内打开，不离开登录流程。

**埋点**：`login_start` `otp_sent` `login_success` `login_failed`。

## 2. 账号（策划书 §6.15）· You 页签

```
┌────────────────────────┐
│ ░░ 天空区 ░░░░░░░░░░░  │
│ ◯  Alex Morgan         │
│    United Kingdom  EN  │
│                        │
│ ┌────────────────────┐ │
│ │ Trip pass          │ │  ← 通行证卡
│ │ Unlimited changes  │ │
│ │ and priority help. │ │
│ │ $9.90 per trip     │ │
│ │           [Get it] │ │
│ └────────────────────┘ │
│                        │
│ My trips            ›  │
│ Bookings and orders ›  │
│ My films            ›  │
│ My souvenirs        ›  │
│ Saved places        ›  │
│                        │
│ Display             ›  │
│ Language            ›  │
│ Become a local friend › │
│ Help                ›  │
│                        │
│ Privacy                │
│ Download my data    ›  │
│ Delete my account   ›  │
│                        │
│ Sign out               │
│ Terms  Privacy  Refunds│
└────────────────────────┘
```

**设计细节**

- **通行证卡**：未购买时，卡片右半边盖着一块长虹玻璃，隐约透出"已解锁"的样子；购买后玻璃滑开，卡片变为 "Active for Shanghai, 13–15 Nov"。购买前写明 "Non-refundable once used"（策划书 §7.1）。通行证功能可由后台开关控制，关闭时整张卡不显示。
- 列表是纸面分组，不用玻璃。
- **订单列表**：每一单是一张小票（与结算页同一样式），右上角是状态印章。
- **导出数据**：点了显示 "We will email you a file within 24 hours."
- **删除账号**：两步。第一步说明后果（30 天后数据匿名化，期间可恢复）；第二步要求输入邮箱确认，输入正确后红色按钮才可点（策划书验收）。
- **Become a local friend**：进入现有的志愿者申请流（`volunteer-application.js`），文案改为英文和中文双语。
- **Display**：适老版开关、减少动态效果、关闭倾斜感应。原有的绿色和橙色主题选项取消。
- 页底常驻三个法务链接（策划书 §6.19）。

**埋点**：`account_update` `account_export` `account_delete`。

## 3. 法务页（策划书 §6.19）

- 三份：Privacy / Terms / Refunds。
- 纯阅读页：纸面、衬线体标题、正文行宽不超过屏宽、行高 1.6。不用玻璃。
- 顶部有目录，点击跳到小节。
- 退款政策页顶部直接放三档退款表（策划书 §7.3），其余条款在下。

## 4. 异常与空状态（策划书 §5.4、§6.20）

**原则**：出问题时告诉用户发生了什么、下一步怎么办，不道歉、不卖萌。

| 场景 | 画面 | 文案方向 | 按钮 |
|---|---|---|---|
| 页面不存在 | 一扇空窗，窗外是纸色 | This page is not here. | Back to my trip / Search |
| 服务出错 | 一扇起雾的窗（磨砂玻璃） | Something went wrong on our side. Code: {code} | Try again / Get help |
| 断网 | 顶部一条薄玻璃横幅 | You are offline. Showing your saved plan for today. | 无（自动恢复） |
| 列表为空 | 一扇空窗 + 一句引导 | 例：No films yet. Pick a few photos to make your first one. | 对应的主操作 |
| 加载中 | 骨架屏：纸色块，超过 300 毫秒才显示 | — | — |

- 起雾的窗：用户可以用手指在雾上擦一下，擦过的地方变清。只是一个小细节，不承载功能。
- 操作反馈：成功提示 2.6 秒自动消失，用 `aria-live` 播报；失败在字段下方就地显示（策划书 §5.4）。
- 提示条是一块薄玻璃胶囊，从底部导航上方升起。

## 5. 权限申请

权限在用到时才要，先用一块厚玻璃弹层说明原因，用户点继续后再弹系统权限框。

| 权限 | 什么时候问 | 说明文案方向 | 拒绝后 |
|---|---|---|---|
| 相机 | 第一次点 Take a photo | 用来拍下旅途中的照片。照片先存在你的手机上。 | 可从相册上传 |
| 定位 | 第一次打开地图或点 Directions | 用来显示你在地图上的位置和步行时间。 | 地图可用，不显示当前位置 |
| 相册 | 第一次进选片 | 用来挑选做成短片的照片。 | 可现场拍照 |
| 通知 | 第一次预约成功后 | 向导确认和出发提醒会通知你。 | 改用邮件 |

## 6. 适老版

导航见《02-导航与信息架构》§7，玻璃处理见《01-视觉系统》§7。页面层面的差异：

- **Today 页**：只有三样东西，从上到下——下一站（大字、中文名可放大）、向导（大头像和 Call 按钮）、Take a photo 按钮。完整时间轴收在 "See the whole day" 里。
- **所有手势都有按钮替代**：登机牌日期选择改为普通日期控件；胶片条拖动排序改为上移下移按钮；下拉开相机关闭。
- **Help 页**：默认直接显示人工联系方式和紧急电话，AI 对话收在下方。
- 每屏主按钮高度 60，文字 18。
- 不显示社区瀑布流；Stories 入口收进 You。
