# 01 视觉系统

> 颜色、圆角、间距、字号沿用策划书 §5.2，一个值都不改。本章只新增"玻璃"和"天光"两组令牌，以及一个补对比度的文字色。新增项都登记在《08-改造落地》§7。

## 1. 颜色

### 1.1 基础色（策划书 §5.2，原样使用）

| 令牌 | 值 | 手机端用法 |
|---|---|---|
| `--paper` | `#F7F2E8` | 页面底 |
| `--surface` | `#FFFDF8` | 卡片、输入框；也是玻璃的底色 |
| `--ink` | `#1B1813` | 标题、主按钮底 |
| `--body` | `#3F3A32` | 正文 |
| `--muted` | `#8B8375` | 只用于图标、分隔、20px 以上的字 |
| `--line` | `#E5DCCB` | 分隔线、描边 |
| `--accent` | `#B24A2C` | "印泥红"：只用于印章、当前站点圆点、链接 |
| `--accent-soft` | `#F2E2D8` | 雨天备选卡底 |
| `--sage` | `#5F6F5A` | 成功、志愿者标识 |
| `--danger` | `#A8322B` | 取消、删除、错误 |

**强调色的纪律**：一屏里 `--accent` 的面积不超过一枚印章大小。主按钮是墨色，不是赭红。

### 1.2 对比度实测（策划书 §5.5 要求 ≥ 4.5:1）

| 组合 | 对比度 | 结论 |
|---|---|---|
| `--ink` / `--paper` | 15.86 | 通过 |
| `--body` / `--paper` | 10.10 | 通过 |
| `--accent` / `--paper` | 4.81 | 通过 |
| `--sage` / `--paper` | 4.82 | 通过 |
| `--muted` / `--paper` | 3.36 | **不通过**，小字禁用 |
| `--accent` / `--accent-soft` | 4.26 | **不通过**，此底上文字用 `--ink` |

**新增 `--muted-strong: #6F685C`**（纸色底上 4.94:1），用于 15px 以下的次要文字，例如"90 min"和"half day"。

## 2. 玻璃

### 2.1 三档厚度

玻璃的底色都是 `--surface`（255, 253, 248），只改透明度和模糊。

| 档 | 令牌 | 透明度 | 模糊 | 饱和 | 用在哪 |
|---|---|---|---|---|---|
| 薄 | `--glass-1` | 0.56 | 12px | 1.10 | 照片上的标签、角标 |
| 中 | `--glass-2` | 0.72 | 22px | 1.15 | 底部导航、顶栏、地图抽屉 |
| 厚 | `--glass-3` | 0.86 | 32px | 1.20 | 弹层、对话框 |

**玻璃上的文字规则**（按最坏情况——玻璃后面是纯黑照片——实测）：

| 档 | `--ink` | `--body` | `--muted-strong` |
|---|---|---|---|
| 薄 | 5.40 可用 | 3.44 禁用 | 1.68 禁用 |
| 中 | 8.75 可用 | 5.57 可用 | 2.72 禁用 |
| 厚 | 12.64 可用 | 8.05 可用 | 3.94 禁用 |

所以：薄玻璃上只放墨色字或图标；次要文字色不上玻璃，除非玻璃后面是纸。

### 2.2 一块玻璃的五层构造

从下到上：

1. **背景模糊**：`backdrop-filter: blur() saturate()`。
2. **底色**：`rgba(255,253,248, α)`。
3. **细噪点**：3% 透明度的噪点图，避免色带，让它像玻璃而不是塑料。
4. **磨边**：上沿 1px 内高光 `rgba(255,255,255,.85)`，下沿 1px 内高光 `rgba(255,255,255,.28)`，外圈 1px 发丝线 `rgba(27,24,19,.06)`。
5. **投影**：暖色双层 `0 8px 24px rgba(60,42,20,.08), 0 1px 2px rgba(60,42,20,.05)`。不用纯灰或纯黑阴影。

### 2.3 三种玻璃质地

| 质地 | 样子 | 含义 | 用在哪 |
|---|---|---|---|
| 清玻璃 | 透亮，看得清后面 | 可以操作 | 导航、按钮、标签 |
| 磨砂玻璃 | 后面只剩色块 | 需要专注读字 | 弹层、对话框 |
| 长虹玻璃 | 竖向棱纹，后面的东西被拉成条 | 还没准备好，或还没解锁 | 生成中的某一天、通行证专属功能、审核中的帖子 |

长虹玻璃是本方案的特色用法：**"看不清"本身就是状态提示**。计划某一天还在生成时，那一天盖着一块长虹玻璃，生成完玻璃滑开。

实现：`repeating-linear-gradient(90deg, rgba(255,255,255,.20) 0 1px, transparent 1px 7px)` 叠在 `blur(10px)` 上，不用 SVG 位移滤镜（性能差）。

### 2.4 地图上的玻璃（特殊）

地图是原生层，在网页下面，网页的模糊够不到它。两种做法：

- **首选**：原生层在地图上方加一层带模糊的 View（Android 12 及以上支持），网页把抽屉和顶栏的位置传给原生。需要改原生代码。
- **兜底**：不模糊，用 0.82 透明度的底色 + 噪点 + 磨边。Android 11 及以下、或不改原生时用这个。

### 2.5 性能上限

- 同屏最多 3 块带模糊的玻璃。
- 滚动列表里的卡片不用模糊，用实色 `--surface`。
- 低端机或系统开启"减少透明度"时，全部玻璃改为 0.94 透明度实色，关闭模糊。

## 3. 天光

页面最上方约 180px 是"天空区"，颜色跟随**目的地城市的当地时间和天气**。游客还在自己国家时，打开 App 看到的是上海此刻的天色。

| 状态 | 当地时间 | 天顶 | 地平线 | 状态栏文字 |
|---|---|---|---|---|
| 清晨 | 05:00–07:00 | `#DDE3EA` | `#F6E3D3` | 墨色 |
| 白天 | 07:00–17:30 | `#DCE8EC` | `#F7F2E8` | 墨色 |
| 傍晚 | 17:30–19:30 | `#C9CBD8` | `#F1D2B8` | 墨色 |
| 夜晚 | 19:30–05:00 | `#1E2530` | `#3A3F47` | 白色 |
| 雨 | 任意 | `#CCD3D6` | `#E6E4DD` | 墨色 |
| 阴 | 任意 | `#DAD9D4` | `#EFEBE2` | 墨色 |

- 天空区向下渐变到 `--paper`，内容区始终是纸色，夜里也不变黑，保证可读。
- 天空区里只放状态栏、顶栏按钮和窗形图片。页面大标题放在天空区下方的纸面上，所以夜晚态不影响标题的可读性。
- 玻璃的高光方向跟着太阳走：上午光从左上来，下午从右上来。只改高光渐变的角度，幅度很小。
- 雨天时，天空区的玻璃上有几道缓慢下滑的水痕（现有 `weather-rain-fall` 动效改造）。
- 数据来自 `GET /api/weather`；断网时只按时间算。
- v1 不做完整深色主题。

## 4. 字体

| 角色 | 字体 | 说明 |
|---|---|---|
| 英文标题 | Source Serif 4 | 开源（OFL）。思源宋体的拉丁字形出自同一个 Source Serif 家族，中英混排协调 |
| 中文标题 | 思源宋体（已内置，CSS 里叫 `Together Song`） | 现有 App 只把它用在社区长文正文；本方案扩大到中文标题 |
| 正文 | 系统字体 `system-ui` | 策划书规定 |
| 数字 | 等宽数字 `tabular-nums` | 时间、价格对齐 |

策划书写的标题字体是 Iowan / Palatino / Georgia，这三种在安卓上都没有，会退回系统默认衬线。所以手机端需要内置一套英文衬线体。

**字号**（策划书 §5.2）：36 / 26 / 20 / 16 / 15 / 13 / 12 / 11 / 10。

| 字号 | 用途 |
|---|---|
| 36 | 每屏最多一个的大标题 |
| 26 | 页面标题 |
| 20 | 卡片标题、价格 |
| 16 | 主按钮、正文重点 |
| 15 | 正文 |
| 13 | 次要信息 |
| 12 | 标签 |
| 11 / 10 | 只用于图片署名等非必读信息 |

**字体体积**：现有思源宋体 5.7 MB。Source Serif 4 只取拉丁字符子集后体积很小，具体数值打包时测量。

## 5. 形状与间距

- **圆角**（策划书）：12 标签 / 16 按钮和输入框 / 20 卡片 / 26 弹层和大玻璃 / 999 胶囊和底部导航。
- **间距**（策划书）：4 / 8 / 12 / 16 / 20 / 24 / 32。页面左右边距 20。
- **主按钮**（策划书）：高 52，圆角 16，墨色实底，白字。主按钮不做成玻璃，它是屏幕上唯一的深色实块。
- **点击区**：不小于 44×44。

**三种窗形**（图片遮罩，新增）：

| 窗形 | 形状 | 用在哪 |
|---|---|---|
| 舷窗 | 3:4 竖向，四角大圆弧 | 首屏、建计划 |
| 月洞门 | 正圆 | 向导头像和向导详情头图 |
| 取景框 | 9:16，圆角 26 | 成片、分享卡 |

## 6. 图标与图片

- 图标沿用现有内联 SVG 线性图标，统一为 24px 网格、1.6px 线宽、圆头。
- 不用 emoji。
- 地点照片用现有 `assets/places/` 下的实拍图，不加滤镜，保留 `credits.json` 的署名。
- 纸面用 2% 透明度的纸纹噪点。现有木纹（`wood-v27.svg`）只用在相册页，当作摆放拍立得的桌面，保留。

## 7. 适老版的玻璃

- 玻璃透明度提到 0.94，关闭模糊。
- 所有玻璃加 1.5px 的 `--line` 描边。
- 字号沿用现有适老值：正文 18、次要 15、标题 28、导航高 80。
- 关闭天光的雨痕和高光移动。
