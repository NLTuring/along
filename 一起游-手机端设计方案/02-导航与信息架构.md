# 02 导航与信息架构

---

## 1. 底部导航：窗台

现有导航是 首页 / 社区 / ＋记录 / 消息 / 我的（`app.js` 的 `nav()`）。改为：

```
        ┌──────────────────────────────────────────┐
        │                                          │
        │   Trip    Friends   ( ◎ )   Stories  You │   ← 中档玻璃，胶囊形
        │    ▔                                     │   ← 当前项下方一道光
        └──────────────────────────────────────────┘
              距屏幕左右各 16，距底部安全区 12，悬浮
```

| 位置 | 英文 / 中文 | 内容 | 对应策划书 |
|---|---|---|---|
| 1 | Trip / 行程 | 随旅程阶段变化的首页（见 §2） | `/`、`/plan/new`、`/plan/[id]`、`/trip/[id]` |
| 2 | Friends / 伙伴 | 向导列表与详情 | `/guides`、`/guides/[id]` |
| 中 | 取景键（无文字，读屏标签 "Capture"） | 拍照、成片、文创、发故事 | `/studio`、`/craft/[craftId]` |
| 4 | Stories / 故事 | 社区 | `/community` |
| 5 | You / 我 | 账号、订单、通行证、设置 | `/account` |

**设计细节**

- 导航条是一条悬浮的玻璃胶囊，不贴底、不通栏，内容从它后面滚过去。
- 当前项不用色块或变色表示，用**一道光**：图标下方一条 16×2 的白色高光，切换时光从旧位置滑到新位置（220ms）。图标本身由 `--muted` 变为 `--ink`。
- 中间的取景键是一枚圆形镜片（直径 56，比导航条高出 8）：外圈磨边，中心是相册最近一张照片的缩小模糊影像。没有照片时是天光色。
- 向下滚动时导航条收缩为只剩取景键的小圆（节省空间），向上滚动恢复。

**取景键的两种用法**

| 操作 | 结果 |
|---|---|
| 轻点 | 弹出厚玻璃弹层，四个选项：Take a photo / Make a film / Make a souvenir / Post a story |
| 长按 0.4 秒 | 直接打开相机（原生 `Android.openCamera`） |

**消息去哪了**：现有的"消息"页签取消。会话入口放在 Trip 和 Friends 两个页面右上角的玻璃圆钮上，有未读时显示一个印泥红小点。理由：策划书里会话是依附于预约的（§6.9），不是独立的社交收件箱。

## 2. Trip 页签：一个页签，四个阶段

第一个页签的内容跟着旅程走，用户不需要自己找"现在该看哪页"。

| 阶段 | 判断条件 | 显示内容 | 主按钮 |
|---|---|---|---|
| A 还没计划 | 本地和账号里都没有计划 | 到达表单（策划书 §6.1 落地页的手机版） | Build my 3 days |
| B 行前 | 有计划，到达时间在未来 | 计划详情 + 距落地倒计时 | Find a local friend |
| C 行中 | 当前时间在行程日期内，或有已确认的预约 | 行程中心：今天的时间轴、向导卡、求助 | 随下一站变化（Directions / Message {name}） |
| D 行后 | 行程最后一天已过 | "带走"提示 + 行程回顾 | Make my film |

多个计划时，页面标题可下拉切换。

## 3. 页面清单与路由

App 内部路由名与策划书 §4 的 URL 保持一致，便于埋点和以后做深链。

| 路由 | 页面 | 进入方式 | 呈现 | 现有代码基础 |
|---|---|---|---|---|
| `plan/new` | 建计划 | Trip 阶段 A | 整页 | 新写；复用 `planner.js` 的数据模型 |
| `plan/:id` | 计划详情 | Trip 阶段 B | 整页 | 改造 `tripPage()` |
| POI 详情 | 地点 | 点时间轴上的站点 | 弹层（不跳页，策划书 §6.4） | 改造 `poiSheet()` |
| 地图 | 地图 | 计划详情和行程中心的 Map 按钮 | 整页，地图在下，玻璃抽屉在上 | 复用 `mapPage()`、`drawers.js` |
| `guides` | 向导列表 | Friends 页签 | 整页 | 改造 `social.js` 里已有的志愿向导列表与搜索；`app.js` 的 `guidesPage()`（AI 向导与路线）并入客服和计划 |
| `guides/:id` | 向导详情 | 点向导卡 | 整页（月洞门转场） | 新写；复用 `guide-profiles.js` |
| `checkout/:bookingId` | 结算 | 向导详情的 Book | 整页，无底部导航 | 新写 |
| `trip/:id` | 行程中心 | Trip 阶段 C；支付成功后 | 整页 | 新写 |
| `messages/:threadId` | 会话 | 右上角消息钮；向导卡的 Message | 整页，无底部导航 | 改造 `chatPage()` |
| `studio` | 选片 | 取景键 → Make a film | 整页 | 改造 `videos.js`、`memories.js` |
| `studio/:filmId` | 成片预览 | 选片后 | 整页，无底部导航，深色 | 改造 `videos.js` |
| 分享 | 分享 | 成片预览的 Share | 弹层 | 新写；复用 `export.js` |
| `craft/:craftId` | 文创 | 取景键 → Make a souvenir | 整页 | 改造 `craft.js` |
| `community` | 社区 | Stories 页签 | 整页 | 改造 `communityPage()` |
| `account` | 账号 | You 页签 | 整页 | 改造 `profilePage()` |
| `login` | 登录 | 任何需要登录的操作 | 厚玻璃全高弹层 | 新写 |
| `support` | 客服 | You；行程中心的 Help；异常页 | 整页 | 改造 `service.js`、`private-assistant.js` |
| `legal/:doc` | 法务 | You 页底；登录弹层 | 整页 | 新写 |

**登录用弹层而不是整页**：策划书要求登录后"回跳保留原页面与选择"（§6.16）。在 App 里用弹层盖在原页面上，登录完弹层收起，原页面和已选时段原样还在，不需要真的跳转。

**不进 App 的页面**：`/admin/*` 后台只在网页端。

## 4. 层级与返回

```
页签页（有底部导航）
  └─ 二级页（顶栏左侧返回箭头，底部导航保留）
       └─ 流程页（结算、会话、成片预览：隐藏底部导航，避免误触离开）
            └─ 弹层（地点、分享、登录、筛选）
```

- 安卓返回键：先关弹层，再回上一页；在页签页连按两次退出。
- 弹层可下拉关闭、点遮罩关闭；打开时焦点锁定在弹层内（策划书 §5.5）。
- 支付进行中禁用返回（策划书 §6.7）。

---

## 5. 顶栏

- 页签页：左侧是页面大标题（衬线体 26），右侧最多两个玻璃圆钮（消息、语言或筛选）。没有 logo 栏。
- 二级页：左侧返回，中间标题在滚动超过 40px 后才淡入（之前标题在内容里）。
- 顶栏背景默认透明，内容滚到它下面时变为中档玻璃。

---

## 6. 语言

- 默认英文，可切中文（策划书 §5.1）。
- 切换入口：You 页面，以及首次打开时到达表单右上角。
- 地点名英文为主、中文小字在下（策划书 §6.4），方便游客把中文给司机看。

---

## 7. 适老版导航

现有适老版是 3 个页签：地图 / 向导 / 消息。入境版改为：

| 位置 | 名称 | 内容 |
|---|---|---|
| 1 | Today / 今天 | 只显示今天的时间轴和下一站 |
| 2 | Friends / 伙伴 | 向导，联系方式放最前 |
| 3 | Help / 求助 | 默认接人工（现有适老版已是人工客服默认） |

- 导航条通栏贴底、不悬浮、不收缩，高 80，图标加文字。
- 取景键移到 Today 页面内，作为一个带文字的大按钮 "Take a photo"。
- 开关位置：You → Display → Larger text and simpler layout。
