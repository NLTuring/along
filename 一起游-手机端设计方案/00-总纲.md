# 一起游 InsTrip 手机端设计方案 · 00 总纲

> 版本 v1.0 · 2026-11-11 · 对象：一起游 APK v2.7.0（`com.linliquan.app`）
> 范围：只重做 APK 里的界面层（`assets/`）。网站不动，原生壳尽量不动。
> 需求源仍是《01-产品功能策划书》。本方案新增或改动的地方，统一登记在《08-改造落地》的"待产品决策"表里。

---

## 1. 一句话概念：一扇窗

**透过一扇窗看中国。** 整个 App 的玻璃都是"窗"，窗后面是真实的城市照片和当地此刻的天光。

选"窗"是因为入境游客这 72 小时里一直在隔着玻璃看中国：

| 时刻 | 游客面前的那块玻璃 | 对应产品层 | 窗形 |
|---|---|---|---|
| 落地 | 飞机舷窗 | 到 Landing | 竖向圆角长方（舷窗） |
| 路上 | 沪宁高铁车窗、园林的月洞门和花窗 | 游 Together | 正圆（月洞门） |
| 离开 | 相机取景框、手机屏幕 | 带走 Studio | 9:16 取景框 |

同一块玻璃在三层之间变形，就是这款 App 的记忆点。南京本身也有琉璃的传统（大报恩寺琉璃塔），这个概念在"上海 + 南京"首发走廊里站得住。

---

## 2. 五条设计原则

1. **玻璃无色，颜色来自照片和天光。** 玻璃本身只有白、透明和一点暖灰。画面里的颜色只有两个来源：用户和地点的真实照片，以及目的地当前时刻的天色。
2. **纸在下，玻璃在上。** 内容（行程、向导资料、价格）写在纸面上，用策划书 §5.2 的纸色令牌。玻璃只给"浮起来的东西"：导航、抽屉、弹层、悬浮按钮、照片上的标签。一屏里玻璃面积不超过三分之一。
3. **玻璃只有三档厚度。** 薄、中、厚，各有固定的模糊和透明度。现有代码里 100 多处各不相同的模糊值全部收敛到这三档。
4. **光会动，东西不乱动。** 唯一持续存在的环境动效是天光的缓慢变化。其余动效都只回应手指：打开、展开、确认。
5. **一屏一件事，英文优先。** 每屏只有一个主按钮。文案先写英文，中文为第二语言，全部走 i18n key。

## 3. 明确不做的视觉（针对"AI 味"）

- 霓虹描边、彩色发光阴影、荧光色。
- 紫蓝渐变、渐变文字、渐变按钮。
- 纯黑底配一个高饱和强调色。
- 所有卡片同一个圆角、同一个灰阴影。
- 每个标题上方加一行全大写小标签。
- emoji、感叹号（策划书 §5.1 已禁止）。
- 进场时每个区块都淡入上滑。

## 4. 保留什么，改什么

| 项 | 现状（v2.7.0） | 方案 |
|---|---|---|
| 技术形态 | WebView + 原生地图/相机 | 保留 |
| 玻璃质感 | 已有，但 100 多处参数不一 | 保留方向，收敛为三档 |
| 宋体 | 已内置思源宋体，目前只用于社区长文 | 扩大到中文标题，新增配套英文衬线体 |
| 天气驱动背景 | 有 | 升级为"天光"系统 |
| 首页下拉开相机 | 有 | 保留，改成"拉开遮光板" |
| 拍立得翻面写字 | 有 | 保留，复用到分享卡 |
| 适老版 | 有，3 个导航项 | 保留，玻璃改为高对比 |
| 绿 / 橙主题 | 3 套可切换 | 合并为一套纸色 + 天光 |
| 木纹 | 只用在数字藏品页，当作桌面底纹 | 保留在相册和分享卡背面，其余页面用纸纹 |
| 语言 | 全中文硬编码 | 英文优先，全部 i18n |
| 导航 | 首页/社区/＋/消息/我的 | 改为 Trip/Friends/取景/Stories/You |
| 短片 | 16:9 | 改 9:16，三种风格 |
| 向导 | 有志愿向导列表、搜索、"聊一聊"和申请认证；没有时段、价格、预约 | 补上时段、价格、预约、结算 |
