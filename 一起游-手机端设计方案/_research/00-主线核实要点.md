# 主线核实要点（一起游 APK v2.7.0，已逐条在代码中核对）

> 供后续设计代理直接引用。每条后面是依据。标"未证实"的不要当事实用。

## 形态
- 包名 `com.linliquan.app`，WebView 混合应用。界面全在 `assets/`：`index.html` 依次加载 23 个 CSS、23 个 JS；DOM 只有 `#app` `#overlay` `#camera-pull` `#toast`。
- 原生层：`MapActivity`（百度地图 SDK 8.2.0）、`CameraActivity`（CameraX）、`CitySearch`、`PhotoStore`。
- CSP 白名单里写死了 `http://172.20.9.186:8787`（局域网后端）。

## 导航（app.js `nav()`）
- 普通版 5 项：首页(home) / 社区(community) / ＋记录(create) / 消息(messages) / 我的(profile)。
- 适老版 3 项：地图 / 向导 / 消息（`db.settings.senior`，`body.senior`）。
- 其余页面：map、trip、guides、chat、memories、videos、crafts、editor。

## 首页（app.js `home()`）
- 日期行 + "今日 · 城市" + 天气按钮；行程卡片堆（`.card-stack`，上下滑切 3 张）；两个入口"找向导 / 规划路线"；景点横向条。
- 首页下拉超过 105px 打开相机；`#camera-pull` 指示条随手指从 86×28 长到 262×144（app.js 1973–2049 行）。

## 地图
- 原生地图铺在透明 WebView 下面：`body{background:transparent}` + `body.native-map-layer`。
- Web 通过 `Android.setMap({visible, rect, appearance:'light', topFade:42, bottomFade:48, focusId…})` 告诉原生地图的位置和上下渐隐。
- `drawers.js` 的 `MapDrawer`：抽屉三档高度 min(128 或 212) / mid(约 52%) / max，360ms 四次方缓出，尊重 `prefers-reduced-motion`。
- **设计约束**：CSS `backdrop-filter` 只能模糊 WebView 自己的像素，模糊不到下面的原生地图。地图上方的"玻璃"要么由原生层做模糊（dex 里出现过一次 `setRenderEffect`，是否已用于此处未证实），要么用不依赖模糊的做法（半透明色 + 高光边 + 细噪点）。

## 原生桥
- JS→原生 `Android.*`：setMap、prepareExperience、shareText、shareFile、searchTravelRoute、searchCity、pickTrip、openExternal、openCamera、getAppConfig、exportImage、exportCraft、downloadVideo、downloadCraft、askAssistant。
- 原生→JS `window.onNative*`：Config、Location、MapEvent、Photo、Photos、Result、Invite、Experience、CitySearch、TravelRoute、TripImported。

## 现有后端接口（与策划书不一致）
- app.js：`/api/community/session|groups|posts|me`、`/api/assistant`、`/api/trips`、`/health`。
- craft.js：`/projects`、`/jobs/`、`/photo-analysis`、`/projects/:id/design-jobs|design-versions|models|design-confirmations|model-confirmations`、`/assets/:id/download`。

## 视觉现状
- 三套主题 `body[data-theme]`：原色(natural) `--accent #536657` `--canvas #eef3ef` `--ink #242725`；暖橘(orange) `#aa714d` / `#f5eee8` / `#393530`；青绿(green) `#507566` / `#eaf2ed` / `#2e3932`。
- 玻璃配方（refinements-v26/v27）：`--surface-glass: linear-gradient(140deg,#ffffffc2,#ffffff70 55%,color-mix(in srgb,var(--tint) 45%,#ffffff89))`；`--edge-glass: inset 0 1px 0 #ffffffd9, 0 4px 14px #293b3010`；`--chrome-glass: #eef3efcc`；`--radius: 22px`。
- `backdrop-filter` 在 17 个文件里出现 100 多处，blur 从 2px 到 36px、saturate 从 1.1 到 1.25，没有统一档位。
- 字体：`'Together Song'`（内置 `noto-serif-sc-regular.woff2`，5.7 MB）只用于社区长文正文（`reader-v26.css`、`reader-v27.css`，`fonts/README.md` 也这样说明）；界面其余文字是 Noto Sans CJK SC。
- 动效关键帧：journal-appear、surface-open、poi-open、backdrop-in、card-enter、sheet-rise、comments-rise、notice-cycle(18s)、weather-glint(12s)、weather-sun-turn / cloud-drift / rain-fall、craft-progress-flow / breathe、reader-dismiss。缓动 `cubic-bezier(.16,1,.3,1)` 与 `(.2,.8,.2,1)`。
- 适老版：`--body 18px`、`--caption 15px`、`--heading 28px`、`--nav 80px`。
- 木纹（`wood-v27.svg`、`wood-grain.svg`）只用在数字藏品页 `.memory-collection` / `.memory-detail`，不是全局背景。
- 首页背景随天气变化：`--weather-sky` / `--weather-horizon`。

## 功能现状
- 短片（videos.js）：16:9、1920×1080、30fps；风格 自然纪实 / 温暖纪录 / 旅行纪录 / 风景短片 / 活力游记；音乐 晴日漫步 / 山间微光 / 出发时刻 / 不加音乐。
- 文创（craft.js）：冰箱贴 magnet / 钥匙扣 keychain；形状 拱形 / 椭圆 / 花边 / 圆角方形；风格含 水墨建筑、浮雕、chibi；three.js 查看器。
- 数字藏品（memories.js）：拍立得卡片，翻面写字，可"发布到旅友圈"。
- 向导有两处：`app.js` 的 `guidesPage()` 是"小宁 · 智能向导"、南京文旅入口和精选路线；`social.js` 里有真人"志愿向导"列表、搜索和"聊一聊"（身份有 大学生志愿者 / 社区志愿者）。两处都没有时段、价格、预约。志愿者申请流存在（volunteer-application.js）。
- 页面加载地址：`https://appassets.androidplatform.net/assets/index.html`（dex 里的 `WebViewAssetLoader`）。
- 清单：versionCode 10、minSdk 23、targetSdk 34、`extractNativeLibs=false`；签名含 v2/v3，签名者 `CN=LinliQuan`（自签）。

## 与策划书的主要差距
- 语言：全中文硬编码；策划书要求 en 优先、zh 次要、全部走 i18n key。
- 缺：建计划表单与生成流程、真人向导时段与预约、结算、行程中心、通行证、邮箱验证码登录、客服页、法务页、分享面板。
- 改：成片 16:9 → 9:16（1080×1920，15/30/60s，3–12 张）；风格枚举改为 `CHINA_TRAVEL` `STREET_FOOD` `SLOW_WALK`。
- 策划书设计令牌是纸感暖色（`--paper #F7F2E8`、`--ink #1B1813`、`--accent #B24A2C`）；现有 App 是绿/橙玻璃。两者需要在手机端方案里统一。
