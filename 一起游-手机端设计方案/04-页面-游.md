# 04 页面设计 · 游（Together）

> 文案 key、接口、埋点、验收沿用策划书对应小节。价格、时限、退款比例全部来自策划书 §7，这里只写呈现方式。

---

## 1. 向导列表（策划书 §6.5）

**目的**：三秒内决定选谁。

```
┌────────────────────────┐
│ ░░ 天空区 ░░░░░░░░░ ✉  │
│ Someone who knows      │  ← guides.title
│ the way                │
│ Half a day, at your    │
│ pace. …                │
│                        │
│ (Shanghai)(Sat 14)(Photography)(English)(Price)  ← 筛选胶囊，横向滑动
│                        │
│ ┌────────────────────┐ │
│ │  ◯   Chen Jiajia   │ │  ← 头像是月洞门（正圆窗）
│ │ 头像  Student volunteer│
│ │      Photography · Slow walks │
│ │      4.9 (32)      │ │
│ │ Free, tips welcome │ │
│ │          [See times]│ │
│ └────────────────────┘ │
│ ┌────────────────────┐ │
│ │  ◯   Zhang Min …   │ │
│ │ from $49 half day  │ │
│ └────────────────────┘ │
│                        │
│ Not sure who fits?     │  ← 匹配入口
└────────────────────────┘
```

**设计细节**

- **头像是月洞门**：正圆窗，直径 72。窗里是向导本人照片；窗沿是一圈磨边玻璃。
- **身份用印章区分**（策划书 §7.4 的两类）：
  - `VOLUNTEER`：`--sage` 色小圆章，文字 "Volunteer"。说明文字 "Walks with you. Does not give guided tours."
  - `LICENSED`：`--ink` 色小方章，文字 "Licensed guide"。
- **卡片是纸，不是玻璃**。列表里不用模糊，滚动才流畅。
- **筛选**：点胶囊从底部升起中档玻璃弹层；选完即时刷新（策划书要求）。已选的胶囊变成实色纸片。
- **没有可约时段**的向导，按钮文字为 "See next dates"。
- **无结果**：一句说明 + "Clear filters" + "Tell us what you need"。
- 首屏至少露出 3 位（策划书验收）：卡片高度控制在 132 以内。

**埋点**：`guides_view` `guides_filter` `guide_open`。

## 2. 向导详情（策划书 §6.6）

**转场**：点卡片，头像那个圆窗放大，变成详情页顶部的大月洞门。这是"游"这一层的招牌转场。

```
┌────────────────────────┐
│ ←                  ✉   │
│      ╭────────╮        │
│     ╱          ╲       │  ← 大月洞门，直径约屏宽 62%
│    │  向导照片   │      │    窗后是向导在城市里的照片
│     ╲          ╱       │
│      ╰────────╯        │
│ Chen Jiajia     ●Volunteer │
│ Design student, film photographer │
│ Shanghai   4.9 (32 trips) │
│                        │
│ I'm a design student…  │
│                        │
│ Speaks  English, Chinese │
│ Good at Photography, Slow walks │
│                        │
│ When                   │
│ ┌──┬──┬──┬──┬──┬──┬──┐ │  ← 未来 14 天，横向滑动
│ │14│15│16│17│18│19│20│ │
│ └──┴──┴──┴──┴──┴──┴──┘ │
│ [09:00 half day] [14:00 half day] │
│                        │
│ Reviews (5)            │
│ Safety                 │
├────────────────────────┤
│ Free + $4 service fee  │  ← 底部固定条，中档玻璃
│ [ Book Sat 14, 09:00 ] │
└────────────────────────┘
```

**设计细节**

- **时段是小玻璃窗格**：可约的是清玻璃；已被占的是磨砂玻璃，不可点；选中的变成墨色实块。日期条上，有空的日子下方有一个小点。
- **底部固定条**：价格与主按钮。没选时段时按钮是禁用态，文字 "Pick a time"；选了之后变为 "Book {slot}"（策划书文案）。价格旁写明含 $4 服务费。
- **未登录点预约**：登录弹层升起，登录完弹层收起，已选时段还在（策划书要求）。
- **评价**：最近 5 条，每条是一张小纸片，带评分、日期、国家。
- **安全说明**：一个可展开的区块：实名核验、培训、行程留痕、紧急联系人。
- **向导暂停接单**：隐藏时段和预约条，显示 "Not taking bookings right now"。
- **无可约时段**：按钮变为 "Message us"。

**埋点**：`guide_view` `guide_slot_select` `guide_book_click` `booking_requested`。

## 3. 结算（策划书 §6.7）

**目的**：一次完成，不丢单。无底部导航。

```
┌────────────────────────┐
│ ←  Review and pay      │
│                        │
│ ┌────────────────────┐ │
│ │ ◯ Zhang Min        │ │  ← 订单摘要，做成一张"票"
│ │ Sat 14 Nov         │ │
│ │ 11:00–15:00 half day│ │
│ │ 2 people           │ │
│ ├╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌┤ │  ← 撕票线
│ │ Guide          $49 │ │
│ │ Service fee     $4 │ │
│ │ Total          $53 │ │
│ └────────────────────┘ │
│                        │
│ How to pay             │
│ (●) Pay now by card    │
│ ( ) Pay cash on the day│
│                        │
│ Free cancellation up to│
│ 24 hours before.       │
│                        │
│ Contact  you@mail.com  │
│                        │
│ [ Pay $53 ]            │
└────────────────────────┘
```

**设计细节**

- **订单是一张票**：纸面卡片，中间一道撕票线，左右各一个半圆缺口。上半是行程，下半是价格。
- **状态用印章表示**（招牌交互"盖章"）。票的右上角留一个印章位：

| 预约状态 | 印章 | 样子 |
|---|---|---|
| `REQUESTED` | Requested | 虚线圆圈，空心，旁边是 12 小时倒计时 |
| `CONFIRMED` | Confirmed | 墨色实线圆章 |
| `PAID` | Paid | 印泥红实心章，盖下时有一次轻微下压和震动 |
| `CANCELLED_BY_TRAVELER` / `EXPIRED` | Cancelled / Expired | 灰色章，带一道斜线 |

- **支付方式**：两个单选。选 Cash 时主按钮文字变为 "Confirm, pay cash on the day"。
- **点主按钮后**：按钮内出现转圈并禁用（策划书 §5.4）；Card 方式跳转 Stripe Checkout（在系统浏览器或应用内浏览器打开），返回 App 后轮询订单状态。
- **支付成功**：票面盖上红色 Paid 章，1 秒后票向上收起，进入行程中心。
- **支付失败**：显示错误码对应的文案和 "Try again"。
- **超时**：显示 "See my booking"。
- **防重复**：按钮点一次即禁用；请求带幂等键（策划书技术规格）。
- 取消政策一行常驻；点开是完整的三档退款表（策划书 §7.3）。

**埋点**：`checkout_view` `checkout_method` `payment_started` `payment_succeeded` `payment_failed`。

## 4. 行程中心（策划书 §6.8）· Trip 阶段 C

**目的**：行程中一页搞定。

```
┌────────────────────────┐
│ ░ 天空区（此刻天色）░ ✉ │
│ Today, Sat 14 Nov      │
│                        │
│ ┌────────────────────┐ │
│ │ Next               │ │  ← "下一站"卡，中档玻璃，
│ │ West Bund riverside│ │    后面是该地点照片
│ │ 14:00  in 35 min   │ │
│ │ metro 25 min       │ │
│ │ [Directions]       │ │
│ └────────────────────┘ │
│                        │
│ ┌────────────────────┐ │
│ │ ◯ Zhang Min  ●Paid │ │  ← 向导卡
│ │ Meets you 11:00    │ │
│ │ [Message]  [Call]  │ │
│ └────────────────────┘ │
│                        │
│ 09:30 ✓ Yu Garden      │  ← 已过的站点变淡并打勾
│ 12:00 ✓ Noodles        │
│ 14:00 ● West Bund      │
│ 18:30 ○ Dinner         │
│                        │
│ [Add to calendar] [See full plan] │
│ Make a film of today   │
│ Need help              │
└────────────────────────┘
```

**设计细节**

- **"下一站"卡是这一页唯一的大玻璃**。它后面是下一站的照片，玻璃上只放墨色字（中档玻璃规则）。每过一站，卡片内容向上翻一格换成下一站。
- **时间轴上有一条"现在"线**：一条细的印泥红横线，随时间向下移动。
- **待确认状态**：向导卡上是虚线 Requested 章和倒计时 "Huang Junjie has 9 h 12 min to confirm"。
- **已取消**：向导卡变灰，显示退款状态。
- **向导结单后 2 小时**：页面顶部出现评价卡（五颗星 + 一句话），14 天内有效（策划书 §7.5）。
- **离线**：今天的时间轴、向导电话、地点中文名都缓存在本地，断网可看（策划书验收）。顶部显示一条离线横幅。
- **加日历**：生成 .ics，交给系统。
- **取消预约**：在向导卡的更多菜单里。点了先显示按当前时间算出的退款比例，再二次确认。

**埋点**：`trip_view` `trip_chat_open` `trip_cancel` `review_submit`。

## 5. 会话（策划书 §6.9）

**目的**：行中最低成本沟通。无底部导航。

- 顶栏：对方的月洞门小头像、名字、身份章。
- 消息气泡：对方的是纸色，自己的是墨色实底白字。**气泡不用玻璃**，保证阅读。
- 输入栏是中档玻璃条，贴在键盘上方。
- **快捷句**（策划书的三句）做成输入栏上方的三张小纸条：I'm here / Running 10 min late / Where is the meeting point? 点一下直接发送。
- **翻译**：长按对方消息，气泡下方展开译文，不替换原文。
- 发送即显示（乐观更新）；失败的气泡旁边出现重试图标。
- 图片消息：点击放大，下拉关闭。
- 空会话：一句引导 + 三张快捷句纸条。
- 5 秒轮询（策划书）。

**埋点**：`chat_open` `message_sent` `quick_reply`。

## 6. 客服（策划书 §6.17）

**目的**：求助 30 秒内有人。

- 顶部是一排四个常见问题入口：Payment / Internet / Tickets / Safety。
- 中间是 AI 对话，样式与会话页一致；AI 的回答必须落到"下一步做什么"，以可点的操作卡片结尾。
- **"Talk to a human" 按钮始终固定在输入栏上方**，任何时候两次点击内可达（策划书验收）。点开是邮件和 WhatsApp 两个选项。
- **紧急情况**：识别到医疗、法律、紧急类问题时，AI 不给建议，直接显示人工入口和当地紧急电话（报警 110、急救 120），电话号码可一键拨打（策划书规则）。
- 行程中心的 "Need help" 和异常页都通向这里，带上来源参数。

**埋点**：`support_open` `support_ai_message` `support_human_click`。
