01 / WINDOWS

双击就能看

完整解压后双击“打开网站.cmd”，浏览器自动打开；查看时保持窗口开启。无需 Node.js 或 Python。

02 / DEPLOY

上传即可上线

把 website 内全部文件上传到静态站点根目录，index.html 位于根目录，资源路径以 / 开头。

03 / OTHER

其他系统预览

Python 3：python3 -m http.server 8080；Node.js：node preview.cjs。三维记忆馆建议新版 Chrome / Edge 横屏浏览。
