# 独立终检任务（只看、只报告，不改任何文件）

你是这支 90 秒产品介绍视频的独立审片人。你没有参与制作，请按标准挑问题。全部用中文报告。

## 材料
- 成片：`along-promo/out/along-promo-v2.mp4`（1920×1080，30fps，2700 帧，无 BGM：旁白 + 小游配音 + 音效）
- 审片帧：`along-promo/out/review/`（每个镜头 5 张全尺寸帧 `Sxx-f<帧号>.jpg` + 一张横排小图 `sheet-Sxx.jpg`，清单 `index.json`）。需要更多帧时可以用 ffmpeg 从成片抽：`ffmpeg -v error -y -i <成片> -vf "select='eq(n\,帧号)'" -frames:v 1 <输出.jpg>`，输出放 `out/review/extra/`。
- 制作依据：`docs/design-spec.md`（产品简报、需求决策表、视觉方向、tokens）、`docs/storyboard.md`（分镜、台词、接缝）。台词全文 `src/vo-lines.json`；字幕时间表在 `src/timeline.ts` 的 CAPTION_LINES。
- 审片标准：`video-shotcraft` 技能的 `references/final-review.md` 与 `references/aesthetic-rules.md`（全文读完再看片）。
- 用户的原始要求（最重要）：
  1. 先讲市场：日韩、欧美来华旅游需求，以及外国游客来华遇到的痛点（清楚列出）。
  2. App 部分：AI 助手小游开场（导航、翻译、行程），后面的功能由小游带着讲、小游在画面里自由地动；按热门景区生成行程；导航 + 预约本地伙伴；长按中间按钮拍照、发社区或 TikTok；照片生成 3D 文创、能切换风格、能申请邮寄到家（用外滩那张合照）。这部分要在一台可以自由旋转摆放的 3D 手机上展示。
  3. 简单讲产品计划：对接国际旅行社的入境游业务。
  4. 网站部分：记忆馆里的 3D 文创连续转一会儿，挑出一件展示；之后必须有 3D 文创拼成 Along 标志的画面；标志拼好后网站里的 3D 小游跳出来，然后出现口号「让世界一起游」。
  5. 旁白真实女声、小游稚嫩童声；旁白少量；信息密度高；可以没有 BGM；**每个画面之间的切换都要大胆、有创意**。
  6. 中文旁白 + 中英字幕，约 90 秒。

## 要做的
1. 按 final-review.md 的各项检查（产品目标、功能完整性、视觉方向一致、分镜一致、数据与表述是否诚实、音画同步、视觉技术质量），再按 aesthetic-rules.md 逐条打勾（R / Q / S / C / P 编号），每条写「✓」或「✗（帧号 + 现象）」。
2. 逐个看 12 个镜头和 11 个转场：转场是否都不同、是否够大胆，有没有穿帮（闪黑、跳帧、元素突然出现/消失、接缝错位）。
3. 文字：要读的字是否够大、是否被字幕或角标压住、有没有错字或中英不对应、有没有夸大或不实的说法。
4. 声音：用 ffmpeg 看音量（`-af volumedetect`、`ebur128`），说出有没有削波、旁白是否被音效盖住（无法试听时写明你是怎么判断的）。
5. 按严重程度排序列出问题（必须改 / 建议改 / 可不改），每条附帧号或时间码和具体改法建议。
