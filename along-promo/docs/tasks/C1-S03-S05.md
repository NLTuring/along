# 任务 C1：S03 3D 手机 + 小游登场 · S04 三天行程 · S05 导航与本地伙伴

这是全片 App 展示段的前半，也是核心段落。用户要求：App 画面在一台**可自由旋转摆放的 3D 立体手机**上展示；**小游在画面里自由活动**（从屏幕跳出、指点、跟着走）；每次画面切换都要大胆有创意；信息密度高。

先完整阅读 `docs/agent-brief.md`（规则，必须遵守）、`docs/design-spec.md`、`docs/storyboard.md`（S03/T3/S04/T4/S05/T6 前半，接缝契约 S02→S03、S05→S06）。技能库 `video-shotcraft`，先读 `references/aesthetic-rules.md` 全文。入口 `src/entry-C1.ts`（`Range-C1`、`Shot-S03/S04/S05`，全片绝对帧）。全部用中文报告。

## 段落（绝对帧；台词都是小游童声）
**S03（650–905；615 起 pre-roll，在 S02 撕开的护照下面）** 台词 X1（690）："你好！我是小游！导航、翻译、行程，放心交给我！"
- 615–660：天色从黎明转白天（`Sky` dawn→day），3D 手机从下方升起、带角度转正，屏幕是 `zh-trip`。
- `cue('X1','你好')`：小游（`Mascot2D`）从屏幕里跳出，落在手机旁边挥手；九种语言问候气泡（你好 / Hello / こんにちは / 안녕하세요 / Bonjour / Hola / Hallo / Привет / مرحبا）错峰弹出环绕他（卡：`radial-ripple-phone-chips`，读 demo）。`cue('X1','导航')` `cue('X1','翻译')` `cue('X1','行程')` 三枚功能 chip 依次弹出（导航 Directions / 翻译 Translate / 行程 Trip plan）。
- 屏幕：小游助手面板 `zh-assistant` → 长按说话（手机旁一条声纹胶囊，卡：`voice-waveform-live`，读 demo）→ 说到「翻译」时，屏幕被长虹玻璃（App 的竖条纹玻璃）从左到右扫过，扫过处中文界面换成英文（`en-assistant-translate`），表现中英双语。
- T3（885–925）：小游起跳，手机绕 Y 轴翻 360°（卡：`card-flip-reveal`，侧棱受光掠过）。**905 是镜头切点**：S03 把手机转到侧面薄边朝向镜头（rotateY≈90°），S04 从 rotateY≈-90° 接着转回正面，此时屏幕已是行程表单。两边手机位置、大小、天色、小游空中姿态必须一致。

**S04（905–1160）** 台词 X2（950）："告诉我你哪天落地，热门景点，三天行程马上排好！"
- `en-trip-form`：`cue('X2','落地')` 时取景角标锁定日期/时间字段（卡：`scanline-annotate-focus`，读 demo）；屏幕外 3D 注记「落地 Land · Shanghai 2026-11-21 10:00」「3 天 days」。
- `cue('X2','排好')`：行程生成，`en-plan-day1` 的站点卡从屏幕里一张张飞出，悬浮成 3D 时间线（外滩/豫园/上博……用真实截图裁切），分层视差（卡：`depth-layer-moves` · style `multiplane`）；注记逐项锁定：时间、交通、门票、当地花费、**营业时间提醒（红）**。注记 ≥32px，活在同一 3D 空间（审美准则 C3）。
- T4（1135–1175）：机位俯仰到正俯视，悬浮的行程卡落到桌面变成地图图钉（卡：`overhead-camera-moves` · style `overhead-tabletop-drop`，读 demo）。S04/S05 都是你写，自己保证连续。

**S05（1160–1415）** 台词 X3（1185）："想去哪儿，我带你走；还能约一位本地伙伴，陪你一起逛！"
- 1160–1250：纸墨手绘风上海示意图（黄浦江、外滩、豫园、人民广场；手绘示意，不仿任何地图产品，要精致），图钉之间墨线画出步行路线（卡：`draw-svg-trace`，读 demo），标「步行 Walk 12 min」；小游沿路线走（guide 动作）；手机立起显示 `en-poi-yuyuan` → `en-driver-card`（给司机看的大字中文地名）。`cue('X3','我带你走')` 对齐路线。
- 1250–1395：`cue('X3','本地伙伴')`：目的地图钉画圆 → 月洞门光圈从图钉圆心打开（卡：`circle-match-iris`，读 demo；月洞门 = App 伙伴页头图的圆形），门里伙伴轮换：陈佳佳（志愿者 · 免费）/ 张敏（持证向导 $49）/ 黄俊杰（持证向导 $55）（卡：`avatar-bracket-carousel`，读 demo），评分/语言/话题取自截图；然后手机屏 `en-checkout` → `en-booked`，状态印章落下「已预约 Booked」；四条安全承诺 chip（取自 App 伙伴页的安全说明文案）。
- 1395–1415：推进到手机底部中间的取景键（`en-trip` 的 rect `lens`），长按进度环（印泥红）充满。**1415 末帧契约**：画面中心 (960,540) 是取景键特写，按钮直径 180px，外圈红环满圈，背景是屏幕底栏（玻璃 + 纸色）。S06 从这里接。
