# Along 一起游 · 介绍视频 设计 spec（自主自由创作）

模式：自主自由创作（用户 2026-11-17 选定）。阶段 0–3 的判断由制作 Agent 自主完成并记录于此。

## 1. 产品简报

- **产品**：Along 一起游，面向来华外国游客的 AI 旅行 App（Android APK：WebView 页面 + 百度原生地图）＋配套网站（3D 记忆馆）。
- **用途**：产品介绍视频。方向：AI + 出海。
- **受众**：中文母语观众；产品本身面向日韩、欧美来华游客。
- **叙事（用户脚本）**：发现市场 → 做出产品 → 成果落地。①市场与痛点 ②APK 功能（小游开场，后续功能由小游带）③与国际旅行社入境游对接计划 ④网站：记忆馆文创转动→挑一件展示→文创拼 Along Logo→3D 小游跳出→口号「让世界一起游」。
- **必须展示**：小游 AI 助手（导航/翻译/行程）、按热门景点生成三天行程、导航 + 预约本地伙伴、长按中间按钮拍照→发社区/TikTok、照片生成 3D 文创 + 风格切换 + 申请邮寄到家（用用户指定的外滩合照）、记忆馆、文创拼 Logo、3D 小游、口号。
- **硬约束**：APK 画面来自最新 `Along-help-dial.apk`；网站画面来自本机网站分享包；APK 段在一台可自由旋转摆放的 3D 手机上展示，小游在 (2)–(5) 段自由活动；旁白女声 + 小游童声（AI 合成，片尾不加"AI 合成"字样）；旁白少量；信息密度高；可无 BGM；每次画面切换都要大胆有创意；中文旁白 + 中英字幕；约 90 秒；1920×1080 30fps。

## 3. 视觉方向

三个文字方向：
- **A「纸墨印泥 × 天光一日」（选定）**：完全沿用产品 tokens——纸色、墨色、印泥红、鼠尾草绿、宋体大标题；材质是纸纹、墨笔、朱红印章、玻璃。全片天色按产品自己的天光状态走一天：夜航（市场）→ 黎明落地（痛点转产品）→ 白天游玩（产品）→ 黄昏收藏（落地 + 记忆馆）。转场用产品自己的三种窗形和动作：舷窗遮光板、月洞门、取景框、六条错落翻页、印章盖下、浮雕凸起、粉末随风。
- B「夜航」：深蓝黑底 + 暖灯，电影感强，但与产品纸墨视觉脱节，产品段会像两套皮。弃。
- C「票据档案」：登机牌/护照/票根贯穿。产品里有登机牌元素，但全片撑不住，作为 A 的局部道具（护照、登机牌撕存根）吸收。

styleframe：产品已有严格设计令牌（`tokens.css` 注明"不得偏离"）且网站即完整视觉参照，按 pipeline 允许跳过独立 HTML styleframe；以地基组件首批 `remotion still` 静帧作为方向验证。
